# Alpha.8：紧凑布局、搜索输入和 JEI 点击区域

## 改动

生存背包和工作台右侧面板由 218×226 收紧至 202×210 GUI 像素。背包的角色框保持 60×80 比例，盔甲格贴住角色框。主物品栏和快捷栏向上移动，右侧留白减少；工作台 3×3 格向上移动，与主物品栏之间的空白缩小。

左侧配方面板与右侧相接。分类按钮、搜索框和列表上移，列表底框在居中后的实际位置比 alpha.7 下移 2 GUI 像素，页脚按钮和命中区域同步调整。

鼠标点击搜索框时显式设置文本框焦点。配方书的 `searching` 标志保留原版的快捷键首字符语义，鼠标聚焦不再误用该标志，因此键盘输入和直接到达 `charTyped` 的中文字符都可用。

可见合成箭头和可选 JEI 点击区域共用矩形坐标。JEI 注册创建点击区域时捕获新坐标，打开其配方界面后矩形保持不变；只调整原版背包及工作台注册的合成箭头，其他容器与自定义区域维持原行为。未安装 JEI 时不加载其兼容 Mixin。

## 验证

Forge 47.4.0、JEI 15.56.0.205、Curios 5.14.1+1.20.1，中文客户端、1 GiB 游戏堆。临时测试模组提供 100 种木材、100 种金属，共 900 个物品、10,900 条测试配方，包括 10,000 个不同 NBT 输出。

| 检查 | 成功操作数 | 内容 |
| --- | ---: | --- |
| 输入、布局及 JEI | 167 | 英文键盘回调、中文字符事件、焦点退出、过滤缓存；逐一检查合成输入格、区域捕获及原版回退 |
| 合成与槽位 | 89 | 2×2、3×3 原生合成、输出拾取、快捷移动、拖动分配、NBT、标签筛选及小窗口回退 |
| 界面恢复 | 32 | 开合偏好、控件移除、屏幕重新显示、JEI 往返及原版尺寸恢复 |
| 鼠标与分页 | 31 | 禁用/启用页码按钮、空背包格放置、创造栏空格命中和搜索空结果 |

另以真实 X11 鼠标和键盘输入 `planks`，匹配 111 条配方；中文字符输入 `木板` 匹配 110 条配方，材料匹配计数未增加。实际鼠标点击两个界面的箭头均打开 JEI `RecipesGui`。Curios 48 槽位界面保持自身 176 宽布局，返回后恢复 46 槽位的 202 宽基岩风格界面。

原始记录与截图位于 `docs/qa/survival/results/alpha8-*` 和 `docs/qa/survival/images/alpha8-*`。这些检查覆盖上述环境，未复测用户的完整 158 模组整合包，也未新增联机覆盖。

## 构建与安装

使用 JDK 17 执行 `./gradlew build`。安装 `bedrockify-forge-1.9.1-forge-alpha.8+mc1.20.1.jar` 并替换旧版本；运行环境仍需 Cloth Config 11.x Forge 版。测试模组及游戏资源均不进入发布包。
