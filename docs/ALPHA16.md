# alpha.16：经典方块与衰变药水

目标平台为 Java 1.20.1 / Forge。旧版反应器参照携带版 0.11 左右的规则；衰变药水参照现代基岩版。两者原本不处于同一游戏版本。

## 方块和获取

- 旧切石机是完整碰撞的装饰方块，可在创造栏或命令中取得；没有界面、加工用途或生存配方。
- 发光黑曜石发出 12 级光，硬度为 35；须用钻石或下界合金镐挖掘，掉落普通黑曜石。可在创造栏取得。
- 下界反应核以三颗钻石和六个铁锭合成，钻石放中列。挖掘返还这两种材料。

## 下界反应

在主世界以反应核为中心搭建 3×3×3：底层四角金块、其余圆石；中层四角圆石、四个边中点留空；顶层十字形五个圆石、四角留空。生存和创造模式均可点击激活，结构不正确时会显示提示。结构正确时，金块与圆石转为发光黑曜石，生成 17×17、35 格高的下界岩尖塔。反应持续 900 游戏刻，期间周期生成物品与僵尸猪灵；结束后反应核进入完成状态，发光黑曜石变为普通黑曜石。尖塔仅填充空气，不覆盖现有建筑。

点击反馈中的模式错误、激活、玩家距离及高度提示，取自携带版 0.11.0 APK 的 `en_US-pocket.lang` 和 `zh_CN-pocket.lang`。0.11.0 二进制原本禁止创造模式激活；本模组依照测试需求允许创造模式激活，并另加了已结束、维度和无建造权限提示。

尖塔的逐层外形、物品权重和生成频率目前是参照历史描述的拟合值。携带版 0.11.0 二进制已确认其反应计数器在超过 920 刻时结束，并在计数器除以 20 所得的第 10、13、20、22、25、30、34、36、38、40 级执行批量生成；当前 900 刻、每 60 刻单件掉落的实现尚未对齐。批次物品数函数在计数器为 0 时返回 9，为 1–3 时返回 15，为 4–7 时返回 `max(0, random % 42 - 4)`，之后返回 `max(0, random % 27 - 2)`。待确认批次计数器初值、旧版物品表、刷怪槽位和尖塔变化顺序后再调整行为。

已从旧版二进制的普通掉落函数解析出八个等概率分支：萤石粉×3、西瓜种子、棕色蘑菇、红色蘑菇、甘蔗、仙人掌、下界石英×4、南瓜种子。普通掉落种类和单次数量已按此表更新。另有低概率物品函数；调用条件尚待确认，暂不并入普通掉落。

## 衰变药水

注册 `bedrockify:decay` 药水类型：凋零 II，40 秒。饮用、喷溅、滞留和药水箭采用 Java 原版药水载体与作用规则；原版药水箭会将此效果缩短为 5 秒，滞留药水云的基础持续时间为 10 秒。四种形式在创造栏提供，也可用带 `Potion:"bedrockify:decay"` 的原版药水或箭物品命令获取。不添加没有依据的酿造配方。
