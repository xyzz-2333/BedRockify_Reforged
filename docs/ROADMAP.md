# 更新计划

本文件记录版本范围与后续待办。勾选表示已完成；未勾选表示尚待实现或合入。当前目标平台为 Minecraft Java 1.20.1 / Forge。

- [x] 合入基岩式末影珍珠与三叉戟投射参数、闪门生成僵尸猪灵及三叉戟搅拌机；游戏内验收仍按 [开发记录](ALPHA13_dev.md) 执行。

## alpha.15：教育版更新 2

两个阶段都属于 alpha.15，完成后再进入 alpha.16。

### 已有基础

- [x] 元素方块、未知元素与材料分解器。
- [x] 水下火炬、四种彩色火把与四种氯化物。

### 第一阶段：特色方块

- [x] 强化玻璃、强化玻璃板及染色变体：材质、连接、透明渲染、挖掘与掉落规则、创造栏分组。
- [x] 水下 TNT：方块与点燃实体、水下爆炸、红石点燃和连锁引爆。使用独立爆炸行为，保留普通 TNT 的规则。

### 第二阶段：化学工作站

- [x] 化合物创建器：元素输入、配方匹配、产物领取；已有氯化物接入统一化合物体系。
- [x] 元素构造器：质子、电子、中子输入与元素输出。
- [x] 实验台：物质组合、反应结果与配套产物；配方和产物见 [alpha.15 开发记录](ALPHA15.md)。
- [x] 补齐强化玻璃等物品所需的材料及原版制作链。

### 实施约定

- 优先复用现有基岩资源包的材质与本地化，保留资源来源记录。
- 保留创造模式和命令获取，不为工作站额外设计无原版依据的生存合成路线。
- 新增配方采用数据驱动方式；容器的消耗、产出和持久化由服务端负责。
- 验收重点：玻璃连接与渲染、水下/陆地爆炸和连锁引爆、工作站输入输出、单用户占用与忙碌提示、存档重载与数据包重载。
