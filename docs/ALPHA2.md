# alpha.2 修订与验证

日期：2026-10-03。版本：`1.9.1-forge-alpha.2+mc1.20.1`。

## 本轮修订
1. 前向搭桥的潜行限制默认关闭；保留站稳、边缘距离和俯视角等原有条件。统一边缘距离默认值与重置值。
2. 补齐所有英文语言键对应的简体中文；统一分类、选项和说明，并汉化本模组配置界面的搜索框。移除设置说明中的 Mod Menu 入口描述。
3. 默认不启用基岩 1.20.10 以前的船、木桶和蛛网配方；增加默认关闭的怀旧开关。修正 30 份羊毛和床配方的覆盖目标，使其对应 1.20.1 的 `dye_*` 配方名称。
4. 创造飞行不再在松键后强制清零速度。增加 0–100% 的额外减速强度，默认 25%，可选择保留原版惯性或恢复立即停止。
5. 给鞘翅结束滑翔选项使用明确名称，并真正接入悬浮说明；不改变原有触发逻辑。
6. Java 版副标题在新配置和恢复默认时隐藏。
7. 移除未实现功能的 Panorama 设置页。
8. 27 个 Mixin 功能组使用中文名称、说明和重启标记，按稳定顺序显示；底层配置键不变。

## 配方版本基准

Mojang 的基岩 1.20.10 更新记录说明了船移除木锹、木桶改用木板以及删除蛛网拆线配方：
https://www.minecraft.net/en-us/article/1-20-10-update-available-bedrock

这三组旧配方共 11 份资源，仍保存在源码和 JAR 中；现代模式在配方重载时移除它们的覆盖／新增，保留 Minecraft 原配方。只有同时打开合成规则与怀旧开关时才加载这些旧配方。

## 实际验证

环境：Minecraft 1.20.1、Forge 47.4.0、Cloth Config Forge 11.1.136、JDK 17，Loom 开发客户端与单人内置服务端。使用独立测试世界，不修改用户存档。

| 检查 | 实际结果 |
|---|---|
| 构建 | `build` 返回 0；Gradle daemon 记录 `BUILD SUCCESSFUL in 14s`，重映射安装包生成成功；项目没有单元测试，游戏检查由临时开发模组执行 |
| 安装包 | 54 个 Mixin 类齐全、52 个引用映射条目、165 份 JSON 可解析；含 mods.toml、MixinConfigs、Access Transformer、LICENSE 与修改后的 NOTICE |
| 中文 | 中英文各 202 个键，无缺失简体中文键；27 组高级兼容开关均有名称和说明；实际界面显示中文搜索框、配方、飞行和鞘翅说明，且没有 Panorama 页 |
| 默认值 | 新配置生成后：`reacharoundSneaking=false`、`hideEditionBranding=true`、`flyingBrakeStrength=25`、`legacyBedrockRecipes=false` |
| 设置保存 | 在 B 键界面把减速滑块改为 50%，保存后的 JSON 为 50；重新打开并点击恢复默认，再保存后为 25；其余默认开关和 27 组兼容键保持正确 |
| 非潜行搭桥 | 玩家站稳、未潜行时，真实辅助判定 `ready=true`；右键在前方放出石头，服务端方块条件检查输出 `STANDING_BRIDGE_PASS` |
| 创造飞行 | 实际前进与松键采样：25% 为逐步衰减，100% 为立即停止，0% 保留原版惯性；25% 的上升松键采样也保留了非零速度再逐步减小 |
| 配方模式 | 现代、怀旧与关闭三种模式分别执行重载并读取服务端 RecipeManager，全部 `PASS`；核对九种船／竹筏、木桶、蛛网、羊毛与床覆盖、墨囊海晶石、骨粉玻璃、萝卜钓竿排列 |
| 标题与退出 | 新默认配置下 JAVA EDITION 副标题隐藏；世界退出并保存各维度后，客户端正常退出，Gradle 返回 0 |

初次飞行采样在较低高度碰到地形，随后改为在 250 格高度固定位置采集；表中仅使用没有碰撞、实际完成松键的三组样本。速度单位为格／刻，三组松键前的速度均为 0.485077：

| 额外减速强度 | 松键后的第一刻 | 随后第一刻的速度 |
|---|---:|---:|
| 0% | 0.441420 | 0.401692 |
| 25%（默认） | 0.331065 | 0.225952 |
| 100% | 0 | 0 |

垂直上升在 25% 下，松键时从 0.225000 降至 0.101250、0.045563，随后继续衰减。这是可调节的手感设置，没有声称逐帧复刻基岩版的飞行物理。

89 份配方 JSON 内容保留；42 份需要覆盖的资源均能对应到原版配方，其中 30 份使用修正后的羊毛／床名称，47 份额外配方沿用本模组命名空间。Java 1.20.1 原版已支持羊毛和床的跨颜色重染，测试因此使用配方 ID、标签和额外材料规则区分模式，而不把原版已有行为误认为模组新增。

日志、默认配置检查和截图在 `evidence/alpha2/`。临时验证模组源码与复测方法在 `qa/`，不编入安装包；截图中第五个模组为该开发验证模组。

测试时曾遇到测试环境的构建缓存锁遗留，清理后构建和游戏运行通过。Unix socket 能力探测的环境处理仍只存在于本机工具缓存，没有放入源码或安装包。没有启动通过 EULA 的专用服务器；普通启动器安装、完整联机、整合包兼容和 Forge HUD 的既有缺口仍见 `PORTING.md`。
