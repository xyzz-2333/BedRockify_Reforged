# GUI、工作站与成就维护边界

- `client/gui/BedrockGui` 提供 survival.png 的面板、槽位、按钮、高亮和箭头。材质路径与采样坐标保持原样；容器传入尺寸与槽位，不再依赖生存背包的渲染类。化学界面自己的材质和 18 像素槽位仍由 ChemistrySprites 绘制。
- `ContainerScreenPolicy` 统一检查开关、精确屏幕类型、原始槽位数量和最小窗口尺寸，返回明确的回退原因。界面负责恢复坐标/槽位并调用原版初始化；开屏事件使用窗口尺寸，因为新 Screen 尚未初始化。创造栏使用替换前的槽位快照，特殊标签继续使用原版布局。
- `GroupedList` 共用分组表头、单项保留和展开顺序；创造目录保留基岩分类排序与熟鸡肉图标，配方目录保留优先选择可制作配方的代表项。
- `CreativeScreenLayout` 集中原版创造栏的尺寸、搜索框和分页按钮位置、滚动换算；`CreativeScreenMemory` 管理初始化、标签恢复、搜索恢复和展开状态，Mixin 通过回调接入原版私有方法。原版槽位与搜索结果刷新仍由原版屏幕处理。
- `CreativeScreenContent` 管理目录来源、分组行和表头查询；`CreativeScreenRenderer` 集中背景、前景、标签及搜索框绘制。Mixin 保留原版标签绘制顺序、槽位写入、输入取消及私有方法接入；不再负责目录组装或像素绘制。
- `GridViewport` 只处理行数、滚动与拖动换算；物品领取、配方可制作性、分组代表项和输入生命周期仍归各自界面。
- `ChemistryStationKind` 表达内部工作站规则；原有字符串 ID 继续用于注册、开屏包与配方。`ChemistryLayout` 集中输入/输出及玩家背包坐标，`StationSlots` 共享菜单索引和玩家槽位构建。
- 化学预览与领取共用无副作用的反应解析，领取时重新查找配方。预览不写入方块存档；旧的真实输出仍先于新配方领取。分解器的提交过程保持独立，不与化学输出槽共用事务基类。
- `MovementAchievements` 管理移动成就及单个玩家的临时状态，退出或服务端停止时清理。`ContainerAchievements` 管理熔炉燃料/产物、砂轮、织布机、箱子与漏斗相关判定和快照。`AnimalAchievements` 管理狼/猫驯服确认、海豚寻宝等待和羊驼商队，按玩家聚合待确认状态，退出或服务端停止时清理；持久化进度键不变。其余成就仍由 BedrockAchievements 接入事件；原有 Mixin 调用入口保持不变。
- `VillageAchievements` 管理交易累计、村民受伤记录与敲钟后的确认；受伤记录按世界保存，敲钟等待按玩家保存。`MapAchievements` 管理探险地图来源、到达判定与地图室确认；交易模块只调用其地图来源记录入口。两者均纳入退出/停服清理，进度 NBT 键与地图记录格式不变。动物计数和交易累计共用带上限的持久化进度方法。
- `WorldInteractionAchievements` 管理方块放置/破坏、潮涌核心激活、冰霜行者和活塞判定；每位玩家的待确认状态聚合到一个对象，退出与停服时清理。活塞配对记录仍按世界保存。`ItemPickupAchievements` 统一管理营火产物、猫礼物和玩家赠送的来源与拾取确认；来源用弱引用表保存，待确认领取按玩家保存，共用数量减少/实体移除的判定。原有猫礼物和营火 Mixin 入口继续由主类转发，末影珍珠的起点与传送判定归入 `MovementAchievements`。
- 熔炉快照按燃料减少或燃烧剩余容器识别消耗。湿海绵把空桶变成水桶时，不再覆盖正在使用的熔岩燃料来源；真实槽位领取测试同时检查熔岩和普通煤炭的成就判定。
- 开发测试属性每次只选择一个；配置表集中声明源码、资源和运行目录，防止多个属性静默覆盖运行目录。

验证入口：`-PchemistryUiGameTests runServer`、`-Palpha17GameTests runServer`、`-PinventoryUiClient runClient`，最后不带测试属性执行 `clean build`。客户端入口在原有目录、滚动、网络和记忆检查后，额外验证窗口缩放、开关、屏幕子类和附加槽位的回退，以及原版创造栏展开、滚动与搜索的重新打开和缩放生命周期。

成就回归额外覆盖交易累计阈值与玩家隔离、探险地图来源去重，以及地图室的未探索像素、重复中心、不同缩放、中心不连续和退出清理。

世界交互和物品追踪回归覆盖：原木与附魔书架判定、真实潮涌核心延迟激活与退出清理、末影珍珠距离阈值与起点消耗、赠送归属、未拾取/部分拾取、营火和猫礼物来源及生成作用域清理。冰霜行者回归调用原版冻结水面逻辑，验证装备条件、延迟确认、取消与退出清理；活塞回归以红石驱动原版推拉，验证最终方块状态和成就归属。

`SurvivalAchievements` 管理饮食起始快照、海带计时、装备、游玩时长和炼药锅染色进度，保持原有 NBT 键与 Mixin 入口。主类保留事件分发、成就授予、公共计数方法和少量无状态战斗判定；后者无需再引入只转发两种事件的模块。

## 本次整理收尾

最初审阅中的化学解析/领取、工作站类型和槽位布局、NBT 匹配、测试配置，以及新增的公共 GUI/回退策略均已落实。成就按状态和领域拆分、创造栏目录/布局/记忆/绘制提取也已完成；原版注入位置集中保留在 Mixin 中，供未来版本适配。生存进度回归覆盖饮食快照、海带计时、退出隔离、装备、游玩时长与染色位掩码。迁移边界已经整理，未来 Minecraft 版本仍需单独适配和验证。
