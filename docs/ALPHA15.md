# alpha.15：教育版更新 2

记录 alpha.15 的内容与配方。后续工作站界面和交互以 [化学工作站界面](CHEMISTRY_UI.md)为准；继承 alpha.14-update1 的玩法与越肩视角兼容修复。

## 新内容

- 强化玻璃与强化玻璃板：无色及 16 种染色，共 34 个方块；硬度 10、抗爆值 9，直接掉落自身。玻璃板支持连接和含水状态，染色玻璃沿用原版染色玻璃渲染及信标染色能力。
- 水下 TNT：钠元素与 TNT 合成；红石、点火和连锁爆炸生成独立点燃实体。爆炸穿过水，但保留固体方块抗爆能力，不修改普通 TNT；水流体本身不被爆炸移除。
- 化合物创建器：37 个化合物配方，包括已有氯化物。按元素种类与整数计量比例匹配，顺序无关；允许完整的多份原料，一次合成只消耗一份。
- 元素构造器：调整质子、电子与中子数，生成对应元素；要求 1～118 个质子、相等的电子数，中子范围 0～200。中子数写入物品数据并显示于提示。
- 实验台：配方匹配后合成漂白剂、热块、冰弹和超级肥料；无效的非空实验消耗投入材料并得到垃圾。
- 漂白剂：在工作台将染色羊毛、地毯、床和旗帜变为白色基础物品。
- 热块：周期融化相邻范围的冰和雪层，不发光；超热维度中的冰不产生水。
- 冰弹：投掷后将碰撞点附近 3×3×3 范围的水方块变为冰，不冻结含水实体方块。
- 超级肥料：作物直接成熟；其他支持骨粉的植物按其生长入口推进，最多四次。
- 创造栏新增强化玻璃、强化玻璃板及化合物折叠组；原有水下火把与彩色火把保留。

## 工作站交互与数据

- 元素构造器和化合物创建器采用预览领取，领取时由服务端提交；实验台通过按钮反应，播放动画后在上方生成产物。具体领取和旧输出兼容规则见[界面说明](CHEMISTRY_UI.md)。
- 真实库存和构造器参数由方块实体保存；预览不是实际库存，不随拆除掉落。
- 服务器校验玩家距离和对应方块实体，拒绝过期或远距离菜单操作。
- 工作站通过创造模式或命令获取；不添加自定义生存工作站配方。
- 教育配方位于 `data/bedrockify/recipes/education/education2`，独立于基岩原版配方替换开关。
- `bedrockify:chemistry` 配方包含 `station`、按物品 ID 计数的 `inputs` 和 `result`；可通过数据包覆盖。

## 实现边界

- 元素构造器记录中子数，但不对照完整的真实同位素有效性表；元素方块放置后不保存同位素物品数据。
- 工作站布局、实验动画与单用户占用已更新，统一见[界面说明](CHEMISTRY_UI.md)，
- 超级肥料对模组植物调用其骨粉接口，具体生长结果由该植物决定。
- 冰弹、热块仅处理已加载位置，不主动加载额外区块。

## 资源与参考

- 新增材质全部直接导入用户提供的原版教育资源包；未自行绘制替代方块材质。热块使用原始多帧纹理。
- 导入工具：`docs/tools/import_education2.py`；逐文件来源和 SHA-256：`docs/education2_resources.json`。
- 化学工作站与制作链参考：[Minecraft Education 化学手册](https://education.minecraft.net/content/dam/education-edition/software-downloads/Chemistry-Lab-Journal.pdf)。
- 强化玻璃数值参考：[Minecraft Wiki](https://minecraft.wiki/w/Hardened_Glass)。

## 验证工具

- `python docs/tools/validate_education2.py`：来源哈希、配方唯一性、模型材质引用及名称。
- `gradlew -Peducation2GameTests runServer`：工作站计量、消费、存档、输出槽、玻璃连接、点燃和水下爆炸。
- `gradlew -Peducation2Client runClient`：在独立 `regression` 测试世界中核对模型、界面和实体同步；该夹具会修改测试世界，不用于普通存档。
- 正式包使用不带测试属性的 `clean build`，排除测试代码。

## alpha.15 初版验证记录

- 7 项 Forge GameTest 通过：37 个化合物配方与库存持久化、实验台与菜单限制、元素构造和玻璃连接、水下爆炸、红石点燃与引信保存、热块与超级肥料、冰弹碰撞。
- 客户端核对 205 个已注册教育物品的模型与材质，三个工作站界面截图检查通过；真实菜单打开、输入扣除及输出同步通过。水下 TNT 自定义实体已在客户端出现并获得渲染器。
- 78 项教育版新增/复用材质来源哈希、41 个化学配方、原 alpha12 资源和 64 项水色校验通过。

## 显示修正

- 水下火炬在空气和水中显示白色粒子，水中另保留气泡；落地和墙面形式一致。
- 中文物品名称统一为“水下火炬”，资源导入工具保留此译名。
- 水下 TNT 点燃后按原版引信节奏闪白，保留末段膨胀与水下爆炸行为。
- 模组显示名称统一为 `BedrockIfy Reforged`；版本由模组版本字段及 Release 标注。
- 客户端回归通过：调用干湿两态、落地与墙面粒子逻辑，并实际执行水下 TNT 引信 80、75、4 tick 的渲染路径；模型、工作站菜单同步回归通过。
