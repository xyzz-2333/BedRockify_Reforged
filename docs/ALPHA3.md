# alpha.3：经典版创造物品栏

参考：用户提供的基岩版 1.21.9 经典界面截图。运行目标仍为 Minecraft Java 1.20.1 / Forge 47.4.0 / Java 17。

## 行为

建筑、装备、物品、自然四大分类在当前屏幕中聚合原来的原版分类；不改写全局创造标签、注册表或搜索树。原木、树叶、矿石、种子、染料等放入自然，床、蜡烛、旗帜、箱子和告示牌等放入物品。门、活板门等保留在建筑。未知模组物品按照它原来所在的分类纳入对应分类，模组独立标签与其排序保留。

经典网格最大 17 列 × 7 行，按窗口和 GUI 缩放调整。Forge 上下分类栏、分页按钮和页码保留；背包、已保存快捷栏使用原来的布局。窗口小于 260 × 230 个 GUI 单位时，回退为完整 Java 创造栏，包括全部原版分类。

左键组图标展开或收起，右键取代表物品；有物品拿在鼠标上时左键组图标不会清空手持物品。当前分类右上角可统一展开或收起。展开后保留组头并显示全部成员。搜索结果平铺，继续使用原来的中文名称、标签以及模组独立搜索树。

只扩展客户端的选物槽位。玩家背包、快捷栏、服务端槽位和创造取物网络协议沿用原逻辑；额外选物槽位不会发到服务端。计入物品身份的 NBT 有独立副本，药水、附魔书和模组变体不会因物品类型相同被去重。

## 配置

两项默认开启，旧配置缺少字段时采用默认值：

- `creativeInventory`：经典创造栏布局与四大分类；关闭后重新打开物品栏恢复 Java 界面。
- `creativeInventoryGroups`：折叠同类物品；关闭后经典界面的全部物品平铺。

B 键 → 界面 → 基岩版创造物品栏。高级兼容设置中新增 `client.features.creativeInventory`，可关闭相关注入并重启。新增设置、工具提示和分组名称均有中英文文本。

## 验证

已在 Forge 开发客户端、集成服务器和独立 Forge 测试模组中验证。测试模组添加 12 个可搜索分类、一个自定义物品、两个不同 NBT 的钻石变体，不包含在发布 JAR 中。

| 检查 | 结果 |
| --- | --- |
| `build`、Mixin 引用映射、访问转换 | 通过 |
| 四大分类覆盖原版分类和 Forge 追加内容 | 1486 个不同物品/NBT 身份全部可达 |
| 全部分组展开后的成员完整性 | 四大分类均通过 |
| 模组独立分类及两页 Forge 导航 | 12 个标签及对应物品保留 |
| 模组页自己的搜索框，清空搜索后恢复分组 | 通过；修复了重复刷新导致成员遗漏的问题 |
| 鼠标展开/收起、右键取物、快捷栏交换 | 通过 |
| Shift 获取整组、快捷键取整组、拖动分配 | 通过 |
| 集成服务端的快捷栏取物同步 | 通过 |
| 中文“羊毛”、`#minecraft:planks`、无匹配搜索 | 分别返回 16、11、0 项，结果平铺 |
| 背包页、已保存快捷栏与返回经典页 | 47、54、128 个客户端槽位之间切换正常 |
| 小窗口及恢复尺寸 | 回退后保留全部原版分类，恢复后重新聚合 |
| 关闭经典界面并再次启用 | Java 与经典界面切换正常 |
| 仅关闭分组，保留经典布局 | 建筑 410 个条目平铺，分组数为 0 |
| 中文配置界面与开关保存 | 通过，重新打开创造栏恢复折叠 |
| 两个不同 NBT 的变体分别取物 | 分别保留 `qa_variant:1` 与 `qa_variant:2` |
| 全部展开/收起与滚轮 | 通过，展开建筑显示 426 个条目（包含 16 个组头） |

自动审计的四类原始列表分别含建筑 410、装备 307、物品 448、自然 361 个条目；原版允许物品出现在多个分类，合并后的不同物品/NBT 身份数为 1486。测试模组源码见 `qa/creative/CreativeInventoryQa.java`，截图与最终审计结果见同目录。
JEI/REI/EMI 等侧栏及其他替换创造界面的模组未进行组合测试。1.21.9 新增而 1.20.1 没有的物品不会凭空加入；本轮复刻界面、分类及折叠行为，没有照搬逐格排序。完整远程联机仍未验证。
