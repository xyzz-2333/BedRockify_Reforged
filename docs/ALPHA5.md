# alpha.5：生存背包与合成页面

目标：Minecraft Java 1.20.1 / Forge 47.4.0 / Java 17。

## 功能与操作

生存背包和工作台使用基岩经典风格的双面板布局。右侧保留原来的 2 × 2 / 3 × 3 合成槽、结果槽、背包、快捷栏；生存背包同时保留盔甲、副手和玩家模型。

左侧配方页提供全部、建筑、装备、物品、自然分类。默认折叠同类物品；左键点击组图标展开或收起，右键使用代表配方。搜索结果始终平铺。箭头或滚轮切页，每页最多 48 格。搜索支持名称、物品 ID、配方 ID，以及 `#标签`。合成台图标切换“全部已解锁配方 / 仅可合成配方”。

点击配方调用原版材料填充，之后从结果槽取出成品。Shift 点击、数字键交换、副手、盔甲快捷移动和拖拽分配仍使用原版槽位操作。没有新增自动消耗材料或一次点击直接给物品的协议。

所有配方按配方 ID 保留。分类与折叠只是视图，不合并配方，不抹掉输出 NBT。材料相同但输出不同的重叠配方，由服务器原有的配方匹配决定成品；界面不会强制把它改成当前预览的变体。

只显示原版配方书收录、玩家已解锁且尺寸适合当前网格的合成配方。JEI 专属展示、特殊机器配方和未解锁配方不会因此进入生存配方书。模组材料分组读取 Minecraft 木材标签及 Forge 锭、粒、储物块标签，其他物品保留独立条目。

## 性能与兼容方式

缓存原版配方书集合的分类、搜索文本和输出。配方同步、语言变更时重建缓存；背包或合成输入变化时调用原版材料匹配。搜索、分类、分页和折叠不重新匹配材料，渲染只遍历当前页。

不枚举材料标签之间的排列组合。不替换屏幕处理器，不增删原版槽位；只暂时调整客户端槽位位置，关闭或重新初始化时恢复原位置和原实例。

仅改动确切的原版 `InventoryScreen` / `CraftingScreen`，并要求原来的 46 个槽位。自定义屏幕类、附加槽位菜单，以及小于 470 × 250 个 GUI 单位的窗口，保留原界面。GUI 缩放使有效窗口过小时，可减小 GUI 缩放后重新打开。

JEI 15 的配方书额外区域同步到 190 × 226 个 GUI 单位，避免其侧栏沿用 147 × 166 的旧范围。此兼容注入是可选的，不要求安装 JEI；注入目标不存在时不影响原版界面。Curios 饰品按钮继续使用 Curios 原来的定位和网络逻辑，标题留出按钮位置，饰品页面保持自己的布局。

设置位于 B → 界面 → 基岩版生存背包与合成。布局、折叠默认开启；重新打开界面生效。配方页的开闭状态单独保存。高级兼容设置中的生存界面注入开关需重启后生效。

## 实测记录

在真实 Forge 开发客户端和集成服务器中测试，窗口 1280 × 720，GUI 缩放 2，客户端最大堆 1 GiB，使用软件渲染。独立测试模组注册 900 个物品：100 套原木/木板/楼梯/台阶/门/栅栏和 100 套锭/粒/块。新增 900 条材料转换配方和 10,000 条带不同输出 NBT 的压力配方，共 10,900 条。压力配方故意使用相同材料，供检查配方身份和 NBT 展示完整性，成品仍由服务器匹配。

最终兼容复测同时安装 JEI `15.56.0.205` 和 Curios `5.14.1+1.20.1`，并通过数据给玩家添加实际可操作的饰品槽。

## 资源包外观

新的生存外观集中在 `assets/bedrockify/textures/gui/survival.png`，可用资源包同名文件替换。保留 64 × 64 尺寸和下面的图集位置即可：

| 区域 | 坐标与大小 |
| --- | --- |
| 浅色面板 | `(0,0)`，16 × 16 |
| 深色面板 | `(16,0)`，16 × 16 |
| 普通槽位 | `(0,20)`，20 × 20 |
| 材料不足槽位 | `(20,20)`，20 × 20 |
| 普通按钮 | `(0,44)`，16 × 16 |
| 选中按钮 | `(16,44)`，16 × 16 |

面板和按钮使用三像素边缘的九宫格缩放，槽位纹理按固定大小绘制。原版配方书开关、物品图标和空盔甲/副手图标继续使用 Minecraft 资源。

普通箱子、熔炉等的背景和按钮外观可以用资源包替换；改变槽位数量、位置、容器交互范围或基岩暂停菜单的布局仍需要模组代码。本轮没有改动容器和暂停菜单。
