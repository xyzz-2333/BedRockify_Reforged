# 化学工作站界面改进

目标 Minecraft Java 1.20.1 / Forge。参考用户提供的四张基岩版实机截图、安装资源包 `chemistry/ui/*_screen.json` 的经典布局，以及 [Minecraft Education 化学手册](https://education.minecraft.net/content/dam/education-edition/software-downloads/Chemistry-Lab-Journal.pdf)。不新增配方或生存合成路线。

- 元素构造器：250×220，左侧按 p/e/n 排列数字输入、加减按钮和竖向滑条；支持键盘方向键、Home/End、焦点及旁白。保留既有 p/n/e 属性顺序及 118/200/118 上限。中部显示随参数变化的原子示意，右侧显微镜及平面元素结果图标。示意按电子层显示，较大的原子核用有限粒子代表，具体数量以输入数字为准；不宣称实现同位素稳定性判定。
- 化合物创建器：184×166，烧杯内 3×3 输入、右侧直接预览和领取结果，移除额外合成按钮。预览不消耗材料、不写入方块输出 NBT；真实领取时才按现有配方消耗一批。元素构造器同样采用预览领取，Shift 点击每次领取一批，避免无限元素预览一次填满整个背包。
- 实验台：176×200，三件原版器皿、横排九格和合成按钮；空输入禁用按钮。服务端确认反应后播放原版图集动画，并把结果生成在工作站上方；无效配方沿用既有垃圾产物规则。旧存档若有未领结果，仍可通过显示的结果格领取，不会丢失。
- 材料分解器：205×200，上方一个输入、下方五格加四格交错输出，使用原版连接图。沿用首次领取才提交消耗、未领取预览不保存或掉落的规则；提交后输入格禁用，悬停提示先领完输出。
- 四个界面统一使用 18 像素槽位、居中无阴影深色标题及关闭按钮；服务器与客户端共用布局坐标，保留原版槽位点击、拖放、背包快捷键、物品数量及悬停提示。

同一化学方块只允许一个玩家打开。其他玩家点击时在操作栏显示“该实验台正在使用”。占用只存在于当前有效菜单中，关闭、断线、距离失效或方块移除后释放，不保存进 NBT，也不维护共享多人编辑状态。

图片直接复制自基岩版 1.21.94 原版化学资源包，没有重绘或重采样；文件摘要见 [资源清单](chemistry_ui_resources.json)。烧杯与连接条按原 JSON 的九宫格拉伸，器皿动画按 10 FPS 读取横向帧。

## 验证入口

- `gradlew --gradle-user-home .gradle-user runServer -PchemistryUiGameTests --offline`：既有教育内容 GameTest 加新增的预览/领取、Shift、背包已满、旧输出、参数边界、实验结果及占用释放检查。
- `gradlew --gradle-user-home .gradle-user runClient -PchemistryUiClient --offline`：独立测试世界中的网络菜单、参数输入与滑动、结果领取及四种界面截图。
- 正式 `build` 不带测试属性，测试类不进入发布 JAR。

实现经独立副本验证后合入原仓库；截图、日志和交付 diff 保存在仓库外。ROADMAP 对应项目已标记完成。
