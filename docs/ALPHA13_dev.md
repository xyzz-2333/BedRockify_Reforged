# alpha.13 开发记录

版本：`1.9.1-forge-alpha.13+mc1.20.1`。继承 alpha.12 的教育内容、材质与本地化；本次集中实现投射物与刷怪机制。当前为候选包，尚未发布。

## 投射物

- 末影珍珠重力改为 0.025，空气、水中速度保留比例改为 1。
- 玩家投掷三叉戟速度改为 4，三叉戟重力改为 0.1。忠诚、激流及原有碰撞仍沿用 Java。
- 玩家用弓或弩发射的箭以 5 格/tick 为满速基准；弓仍按原拉弓进度缩放。弩的烟花弹、非玩家射手，以及雪球、鸡蛋、药水、经验瓶不调整。
- 基岩版 1.21.94 的六次玩家箭实测初速均约 5 格/tick，箭的重力 0.05、空气惯性 0.99 与 现在的更新一致.
- 配置 `bedrockProjectiles`，默认开启；服务端规则同步到客户端。
- 投射物参数依据基岩版原版行为包和游戏内采样。

## 闪门生成僵尸猪灵

- 新生成的每个传送门方块触发一次生成尝试，反复熄灭、点亮可重复触发。随机刻也使用相同概率与生成位置规则。
- 仅主世界，遵守 `doMobSpawning` 与难度：每方块尝试概率为简单 1/2000、普通 2/2000、困难 3/2000，和平不生成。
- 仅底部不低于 Y=0 的传送门可生成；X 轴门只在南侧、Z 轴门只在东侧生成。不要求支撑面或无方块碰撞空间；目标区块仍需已加载。
- 直接生成不检查自然生物上限；生成后设置 300 tick 传送冷却。
- 配置 `bedrockPortalSpawning`，默认开启。触发方式与位置是效果近似，尚未逐项证明与基岩相同。
- 发射器将细雪桶对准传送门方块时，先清除该方块，再由原版桶行为放置细雪、返还空桶；相邻传送门方块随结构失效而消失。

## 三叉戟搅拌机

- 无忠诚三叉戟在活塞推动、附近活板门开合或地毯受活塞推动时获得一次攻击机会。水平活板门位于三叉戟下方时也会触发。周围方块状态变化用于近似基岩版的重新碰撞；没有新触发时不会持续伤害。
- 每次触发对其碰撞箱外扩 0.3 格范围内的存活 `MobEntity` 造成 8 点基础三叉戟伤害，并应用三叉戟攻击附魔加成。穿刺依据目标是否接触水或雨计算，护甲等原版减伤保留。
- 搅拌机伤害遵守目标原有的受伤间隔；连续的红石脉冲不会绕过该间隔。玩家不在持续伤害目标中。
- 保留原投掷者的伤害归属；主人手持抢夺武器时按击杀瞬间的抢夺等级掉落。主人离线/未加载时暂停伤害。搅拌机命中不消耗三叉戟耐久。
- 激活状态写入 NBT；开启 `bedrockProjectiles` 时，所有落地三叉戟不因超时消失，仍可正常拾取。忠诚三叉戟不参与搅拌机攻击，保留返回逻辑。
- 配置 `bedrockTridentKiller`，默认开启。关闭后暂停额外伤害。方块检测范围及触发时机仍属于玩法近似，需用实际装置验收。

## 验证与工具

- 自动 Forge GameTest：末影珍珠速度与重力及关闭恢复、玩家弓弩箭速与关闭恢复、闪门生成与开关、搅拌机脉冲伤害、活塞激活 NBT 保存和忠诚排除。
- 测试源码与空结构位于 `docs/tools/mechanics-tests`，仅显式启用时加入开发运行，普通 JAR 不包含这些测试。
- 执行 `gradlew.bat --gradle-user-home .gradle-user -PmechanicsGameTests runServer`。运行的是隔离的 GameTest 服务器，目录 `run/mechanics-tests`。
- 普通发布构建前执行 `clean build`，清除测试编译残留。
- 轨迹计算工具：`python docs/tools/compare_projectile_trajectories.py`。
