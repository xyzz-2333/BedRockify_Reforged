# alpha.13 开发记录

版本：`1.9.1-forge-alpha.13+mc1.20.1`。继承 alpha.12 的教育内容、材质与本地化；本次集中实现投射物与刷怪机制。当前为候选包，尚未发布。

## 投射物

- 末影珍珠重力改为 0.025，空气、水中速度保留比例改为 1。
- 玩家投掷三叉戟速度改为 4，三叉戟重力改为 0.1。忠诚、激流及原有碰撞仍沿用 Java。
- 箭、雪球、鸡蛋、药水、经验瓶不作无依据的射程加成。
- 配置 `bedrockProjectiles`，默认开启；服务端规则同步到客户端。规则网络协议升级为 2，两端需匹配版本。
- 投射物参数依据基岩版原版行为包，具体分析记录保存在本地。当前实现仍需游戏内对照验证。

## 闪门生成僵尸猪灵

- 新生成的每个传送门方块触发一次生成尝试，反复熄灭、点亮可重复触发。现有随机刻生成保留。
- 仅主世界，遵守 `doMobSpawning` 与难度：每方块尝试概率为简单 1/2000、普通 2/2000、困难 3/2000，和平不生成。
- 在底部传送门方块旁边选择两个垂直于门平面的方向，要求支撑面、已加载区块与无方块碰撞空间。门旁需要留平台和净空。
- 配置 `bedrockPortalSpawning`，默认开启。触发方式与位置是效果近似，尚未逐项证明与基岩相同。

## 三叉戟搅拌机

- 无忠诚三叉戟受到非零活塞移动后激活；尚未被活塞激活的普通落地三叉戟不获得持续伤害。
- 激活后每 2 tick 对其碰撞箱外扩 0.3 格范围内的存活 `MobEntity` 造成 8 点基础三叉戟伤害，并应用三叉戟攻击附魔加成。护甲等原版减伤保留。
- 仅此次搅拌机伤害跳过目标的伤害间隔；不全局关闭生物受伤无敌时间。玩家不在持续伤害目标中。
- 保留原投掷者的伤害归属，需要能找到存活的投掷者；主人离线/未加载时暂停伤害，重新可用后恢复。
- 激活状态写入 NBT；激活期间取消原版三叉戟的落地超时消失，仍可正常拾取。忠诚三叉戟不激活，保留返回逻辑。
- 配置 `bedrockTridentKiller`，默认开启。关闭后暂停额外伤害，并恢复原版超时处理。
- 本次为玩法近似：激活后无需每次重新推动，尚不保证所有基岩搅拌机构型在 Java 红石与活塞规则下直接可用。
