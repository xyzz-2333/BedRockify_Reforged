# alpha.12 开发记录

基准：6bd081c（alpha12_update1）。版本：1.9.1-forge-alpha.12+mc1.20.1。

## 2026-10-11 材质与本地化

- 更新原版教育内容的材质：119 个元素（含未知元素）、材料分解器四面、五种火把、四种氯化物。
- 四种氯化物复用资源包中的白色试剂瓶材质。未导入未实现物品、实体或与现有布局不对应的基岩版界面文件。
- 从资源包导入新增内容的 134 个名称字段，覆盖仓库中的 38 个语言文件。西班牙语地区变体复用包内西班牙语；资源包未提供的阿拉伯语、爱沙尼亚语、塞尔维亚语、越南语使用英文回退。
- 中英文配置项、说明、分解器提示、原子序数提示和创造栏分组文字已补齐；检查源码直接引用的翻译键，均有对应中英文条目。
- 资源来源、逐文件 SHA-256、名称语言来源及英文回退数量记录于 `docs/education_resources.json`。
- 原有生成工具保留已导入的材质；重新导入使用 `import_education_pack.py`，避免重新生成素材覆盖更新的的贴图。
- 单人游戏测试：alpha.12 JAR 未发现问题。

## 已实现功能

- 可配置慢速自然回血：跳过饱和度快速回血，默认每 80 tick 恢复 1 点生命值，保留自然回血游戏规则。
- 可配置取消攻击蓄力，保留受伤无敌时间；多人攻击规则由服务端同步。
- 118 种元素及未知元素方块、材料分解器；输入/预览/领取/剩余产物持久化。
- 水下火把、蓝/红/紫/绿火把及四种氯化物；五组火把合成配方和 30 组数据驱动分解配方。
- 元素与氯化物创造栏折叠；教育配方不受原版配方替换开关过滤。
- 分解器菜单同步时重新检查配方，适应打开界面期间的数据包重载；清空、拆除时重置预览缓存，空的已提交存档解除输入锁定。
- 修复 docs/tools 生成脚本的资源输出路径；补回 Gradle wrapper；JSON 固定 UTF-8 / LF。

## 构建与验证

- JDK 17、Gradle 8.8 构建已通过；源码编译、Mixin refmap、访问规则和 JAR 重映射检查通过。项目没有 Java 测试源码。
- 多人、存档持久化、Shift/数字键等边界操作、模组兼容性仍待专门测试。

## 实现范围

- 新增方块与物品要求客户端和服务端安装匹配版本。
- 材料分解器和氯化物目前通过创造/命令获取，没有自定义生存合成配方。
- 彩色火把提供彩色外观与粒子，光照仍使用原版光照。
- 默认分解配方仅覆盖列出的输入；模组物品可通过 `material_reducing` 数据包配方扩展，不按名称猜测组成。

## 工具

Python 3.10+；材质工具另需 Pillow。各工具可从任意工作目录运行。

- `docs/tools/import_education_pack.py <资源包 ZIP>`：导入材质、名称及来源清单。
- `docs/tools/generate_education_assets.py`：生成模型、掉落和火把配方，保留已导入材质。
- `docs/tools/generate_reducing_recipes.py`：生成默认分解配方。
- `docs/tools/update_alpha12_ui_lang.py`：补齐中英文界面文字，不覆盖已有翻译。
- `docs/tools/validate_alpha12_resources.py`：验证资源、配方和本地化完整性。

## 后续验收

1. 新材质与名称的单人复测：创造栏、放置后的元素、分解器各面、地面/墙面火把、物品名称和搜索。
2. 分解器未领取时取出输入、重开界面、重进存档或拆除，不得额外生成产物。
3. 部分领取、满背包 Shift、数字键、丢弃和双击收集：输入只消耗一次，实际转移和剩余数量一致。
4. 两名玩家同时操作同一分解器：总产物不重复，领取完成解锁输入。
5. 打开界面时移除或修改数据包配方：未提交预览更新，已提交剩余产物保持不变。
6. 水桶/岩浆桶返还空桶，水下火把支撑移除和水流更新，以及其他模组的交互兼容性。
