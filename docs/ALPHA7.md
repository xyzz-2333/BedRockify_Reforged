# alpha.7：空位交互与经典界面外观

本轮针对用户提供的创造栏故障图、生存背包故障图，以及基岩版经典生存背包和工作台参考图。

- 创造栏的经典选物网格使用 `CreativePickerSlot`。没有物品的占位格禁用，Minecraft 原生悬停命中、焦点和快捷键路径会跳过这些格；直接取物入口也忽略禁用格。原版保存快捷栏、背包页及玩家空槽仍使用原槽位。
- 配方栏右下的前后翻页图标改为像素三角形，不依赖字体字形。禁用图标与按钮底色保持明显对比；始末页点击不会越界，并有“上一页 / 下一页”的中英文提示。
- 角色区域为纯黑背景，宽高比 3:4；与四个连续盔甲格齐高且紧贴其右侧。模型放大至适合角色栏的高度，副手贴其右下。槽位 ID、库存、网络和服务端配方逻辑保持原实现。
- 槽位去掉旧的双层凹槽边，改为单像素深色上/左边和白色下/右边。主面板为阶梯拐角及细亮边。创造栏使用相同外观；生存槽位和面板仍从原图集取色，保留资源包覆盖能力。
- 2 × 2 与 3 × 3 合成箭头改为像素图形。经典工作台结果槽高亮按实际新槽位大小绘制，原版及其他容器的高亮规则保留。

验证使用隔离的 Forge 开发环境和临时世界；开发测试模组不会进入发布 JAR。测试结果及截图位于 `docs/qa/survival` 和 `docs/qa/creative`。

## 本轮验证

- Forge 47.4.0 / Minecraft 1.20.1 / JDK 17 构建成功，访问扩展与引用映射检查通过。发布 JAR 含 405 个条目，引用映射包含 58 个注入类；不包含测试模组或 Minecraft 本体。
- 客户端堆上限 1 GiB，安装 JEI 15.56.0.205、Curios 5.14.1+1.20.1，并加载开发数据的 900 个物品与 10,900 条配方（含 10,000 个 NBT 输出变体）。
- 针对本轮问题的 5 组检查 / 33 条指令通过：单页禁止越界、多页前后切换、真实空背包格放入物品、空创造占位格原生命中与点击、搜索有结果与无结果的切换。鼠标测试使用原屏幕的按下与释放处理。
- 原有 7 组合成与槽位检查 / 90 条指令通过：2 × 2 填料和取出、盔甲与副手、数字键交换、拖拽分配、搜索/标签/分组、服务端 NBT 成品、真实 3 × 3 工作台配方与 Shift 转移、窗口和配置回退。
- 原有 9 组界面恢复检查 / 32 条指令通过，包含原控件被移除、临时关闭、复用屏幕、退出经典布局以及真实 JEI 配方界面的往返。
- 实际点击 Curios 控件打开其 48 槽独立界面，再点击返回按钮恢复 46 槽经典生存背包与打开的配方栏。
- 创造栏审计确认 1,486 个原始物品/NBT 身份仍可访问，Forge 追加物品及两个 NBT 变体、12 个独立模组标签与两个 Forge 页面保留。
- 中文界面实际截图核对：禁用的前后箭头均可见；角色区域与四格盔甲栏齐高、相邻；工作台使用像素箭头；鼠标停在创造列表末尾空白区域时没有槽位高亮。

本轮未使用用户的 158 模组整合包，也未重新测量 alpha.5 的压力计时数据。首次客户端资源下载/缓存锁问题属于开发环境，完成资源准备后进行上述截图检查；构建依赖的沙箱兼容修补不在项目源码或发布 JAR 中。
