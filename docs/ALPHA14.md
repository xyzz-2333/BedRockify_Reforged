## 盔甲架

- 新放置的盔甲架默认带手臂，可通过原版装备交互持有物品；沿用原版装备交换、存量扣除与 DisabledSlots 限制。
- 潜行右键循环 13 种姿势，并显示中英文动作栏提示。潜行切换不转移物品，副手交互不重复切换；命名牌与标记盔甲架沿用原版处理。
- 六个身体部位的静态旋转来自基岩 1.21.94。来源相对路径、文件摘要及转换规则见 `armor_stand_poses.json`，导入工具为 `tools/import_armor_stand_poses.py`。
- 服务端默认检查盔甲架正下方方块收到的最强信号；`armorStandExtendedRedstone=false`，开启后同时检查盔甲架所在位置和上方，保留初版扩展检测玩法。信号 1～12 对应姿势 1～12，13～15 使用英雄姿势；非零强度变化立即更新，无需先归零，多个输入取最大值。归零时保留姿势，持续相同信号不覆盖手动选择。
- 保存自定义姿势序号与最后信号强度。读取存档保留原版 Pose 和明确指定的 ShowArms，不把未通电的命令自定义姿势重置为预设。
- 常规配置 `bedrockArmorStand` 默认开启；高级兼容开关为 `common.features.armorStand`。专用服务器以服务器配置为准，客户端姿势使用原版实体数据同步。
- 不含基岩动画控制器的晃动与姿势过渡。红石映射采用兼容实现，未逐项还原基岩引擎内部逻辑。

## 潜行举盾

- 通过原版物品使用入口发送请求，由服务端负责格挡、伤害与耐久；优先主手盾牌，其次副手盾牌。
- 自动举盾后维持使用状态，修复原版在右键未按住时每刻取消使用、导致盾牌反复启动的问题。
- 取消潜行、打开界面或关闭功能时释放自动使用。手动右键使用保持原版行为；正在使用其他物品、旁观模式和盾牌冷却期间不抢占。
- 保留 Java 原版格挡启动时间、攻击打断及伤害规则；未增加基岩专属伤害算法或第一人称模型。
- 增加中英文配置说明，保留常规 `sneakingShield` 开关和高级 `client.features.sneakingShield` 开关。

## HUD

- 为 Forge 自行绘制的血量、饥饿、护甲、氧气和坐骑血量加入安全区偏移及透明度。经验条、跳跃条沿用原版入口，避免重复偏移。
- Forge GUI 覆写总渲染入口时，仍能在快捷栏、经验条、跳跃条及状态效果绘制前更新安全区。
- 修复透明度接近零时经验等级、Boss 名称与坐标等文字因原版文字渲染规则而重新变为不透明的问题。
- 生命、饥饿、氧气、护甲、经验变化、物品使用、挥手或快捷栏切换恢复 HUD；切换玩家实例时重置渐隐状态。修正安全区与透明度配置的边界值处理。
- 安全区与透明度高级开关可分别控制 Forge 状态条。未新增 AppleSkin 专项集成，其他模组提供的自定义 HUD 仍需兼容验证。

## 2026-10-14 修订：手臂交互、减速与底座

- 原计划作为 alpha.15 的水色内容已并入本版本，见下文「群系水色」；简单游戏内测试未发现问题，模组兼容性稍后测试。
- 手臂交互使用跟随左右手臂姿势、实体朝向及小型状态的选择区域；客户端补充手臂射线选择，服务端按命中手臂选择主手或副手。穿胸甲、裤子不会抢占手臂命中，不扩大实体的物理碰撞箱。
- 手臂取放沿用原版装备交换，保留数量、创造模式及 DisabledSlots 的放入、取出和总锁定规则；身体区域继续使用原版盔甲槽选择。潜行切换姿势与命名牌行为保留。
- 潜行举盾时保留潜行自身减速（含迅捷潜行），避免再次乘上使用物品的 0.2 倍减速。站立举盾、潜行进食及关闭功能时保留原有减速。
- 底座朝向问题已明确：Java 模型会对底座施加抵消实体 yaw 的旋转；本修订在开启基岩式盔甲架时取消这层抵消，使底座随本体转动，关闭功能时恢复原行为。
- 补充基岩版实测后，按原版设定修订红石规则：默认正下方方块受电，原扩展范围作为可选配置，强度变化立即更新，断电保留。

## 群系水色

- 从基岩 1.21.94 安装中导入水面 RGB 与独立水下雾 RGB。按版本号处理 vanilla 资源覆盖；现代水下颜色读取对应 fog_identifier 的最终雾资源，避免沿用旧版表中的过时参数。
- 完整列出 Java 1.20.1 的 64 个原版群系。按两版名称差异建立明确映射，十个没有专门基岩条目的群系使用源资源 default。高大白桦林使用白桦林家族映射；具体别名、默认继承和来源见 `water_colors_sources.json`，不声称重建闭源引擎的全部群系分类。
- 例如：平原水面/水下 `#44AFF5`；暖海洋水面 `#02B0E5`、水下 `#0289D5`；红树林沼泽水面 `#3A7A6A`、水下 `#4D7A60`。
- 水面与水下入口分别接入原版 Biome 色值读取。原版群系混色设置、颜色缓存及水下颜色过渡仍有效，不把水下颜色简单复制为水面颜色。
- 默认不会给未知群系套用基岩默认色：未映射的模组或数据包群系保留自身色值。
- 只作用于客户端读取，不改写群系注册数据、存档或服务端规则；不需要服务器专门支持水色功能。完整模组中其他共同玩法的安装要求仍沿用原来版本。

### 配置与资源包

- `bedrockWaterColors=true`：群系水色总开关；`bedrockWaterFogColor=true`：独立水下颜色开关；`bedrockWaterColorNoise=false`：在导入水色上叠加原有轻微明暗噪声。
- 默认水面使用导入颜色，不叠加旧噪声；草色噪声保留。关闭新功能后恢复旧版本模组的色值/噪声行为。
- 常规开关保存时刷新群系颜色缓存并重新构建区块显示，不要求退出世界。高级 `client.features.biomeWaterColors` 开关修改后需重启。
- 资源包可覆盖 `assets/bedrockify/water_colors.json`，格式为 `{ "format": 1, "biomes": { "minecraft:plains": { "surface": "#44AFF5", "fog": "#44AFF5" } } }`。
- 多层资源包按优先级合并。已有条目可只覆盖水面或雾色；新增条目必须同时提供两种颜色。条目值为 null 时删除映射、恢复该群系原色，也可明确增加模组群系映射。
- 错误的资源文件整份忽略并记录警告，保留已成功加载的低优先级数据；所有映射均不可用时恢复原有颜色行为。资源重载后刷新颜色缓存。
- 只缓存注册表中的群系身份，不缓存最终色值；区块构建线程使用并发缓存，资源重载不会留下过期颜色，切换世界时更换身份缓存。

### 实现边界

- 水色实现移植颜色，不改变水面材质透明度、水下雾距离、基岩适应曲线或其他雾效果。原版夜视、失明、黑暗与水下可视距离仍走 Java 原有逻辑。
- 基岩表中的透明度与雾距离作为来源信息记录，不能据此宣称水体渲染与基岩引擎逐帧一致。
- 使用原版 Java 水纹理，资源包可照常替换。光影或其他模组若自行提供水色/雾色，可能覆盖此效果，尚未逐项验证。

- 静态覆盖检查：64 个表项与 Java 1.20.1 实际 BiomeKeys 清单一致，水面/雾色值与导入清单对应；中英文常规及高级配置字段检查通过，原有教育材质与名称校验保持通过。
- 隔离客户端自动检查通过（47 秒）：实际 64 个 BiomeKeys 覆盖完整，水色资源加载成功，水面/雾色独立、未知群系回退、常规/高级开关、局部资源覆盖、删除映射、非法色值拒绝与配置页构建均通过；客户端自动退出。

### 工具与复测

- `docs/tools/import_bedrock_water_colors.py <基岩 resource_packs 目录>`：读取带注释的源 JSON、处理覆盖关系并生成水色表与来源清单；本机绝对路径不写入生成文件。

### 游戏内验收清单

1. 平原、沙漠、森林、河流、沼泽、红树林沼泽、暖海洋、冻洋与樱花林：分别观察水面和水下颜色。

## 同版本续修：底座、锋利与创造分组

继续使用 `1.9.1-forge-alpha.14-update1+mc1.20.1`，不增加发布版本号。本轮含下列改动，验证结果见「本轮验证」与「Shoulder Surfing 兼容修复」。

- 修复盔甲架底座保持方块轴向的问题；模型动画更新后将底座局部 yaw 置零，使其跟随实体方向。功能关闭时保留 Java 模型原有补偿。
- 新增 `bedrockSharpness=true`：锋利附魔伤害为 `1.25 × 等级`，I～V 分别为 1.25、2.5、3.75、5、6.25 点。只修改锋利附魔加成，不改武器基础攻击力，不改亡灵杀手和节肢杀手。
- 锋利开关由服务端同步到客户端，伤害与物品提示共用附魔计算入口；断开连接清除临时服务端规则。内部机制协议更新为 3（预留旧 alpha.13 协议 2）。
- 修复部分物品未被正确折叠的问题：折叠只影响目录展示，不改变物品本身、合成或既有存档内容。
- 中英文分组名称、锋利开关及说明同步补齐。

### 本轮验证

- 客户端服务端规则覆盖、断线清理锋利规则、现有盾牌移动输入与 64 项水色加载通过。客户端测试成功退出。
- 模组兼容性尚待复测。

### Shoulder Surfing 兼容修复

- 在 Shoulder Surfing 4.6.3 共存环境复现启动失败：两个 GameRenderer Redirect 争用同一实体射线调用。
- 将手臂命中补充移到 ProjectileUtil.raycast 返回点，保留原命中结果及调用方的射线、距离上限和实体筛选条件；仅处理客户端当前摄像实体的检测。无需增加依赖或禁用越肩视角。
- 删除已经退出 Mixin 配置、但仍调用已移除方法的旧 KeyboardInputMixin，修复源码覆盖后留下的编译错误。
- 新增真实客户端射线回归，覆盖八方向手臂、距离截断、筛选条件与关闭功能。越肩模式会旋转移动输入，兼容回归比较向量长度。
