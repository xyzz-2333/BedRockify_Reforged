# BedrockIfy — 非官方 Forge 1.20.1 移植

本项目基于 BedrockIfy `1.9.1+mc1.20`，目标为 **Minecraft 1.20.1 / Forge 47.4.0 / Java 17**。这是实验性移植，未经上游作者发布或认可。

## 安装与配置

1. 安装 Minecraft **1.20.1** 与 **Forge 47.4.0**。
2. 将本项目构建的 `bedrockify-forge-*.jar` 放入 `mods`。
3. 客户端还需安装 **[Cloth Config 11.x 的 Forge 版本](https://modrinth.com/mod/cloth-config/version/11.1.136+forge)**，构建使用 11.1.136。不要安装 Fabric 版本。
4. 游戏中按 **B** 打开配置，也可以在 Forge 模组列表中打开配置界面。B 可以在按键设置中更改。
5. 第一轮测试使用新建世界。炼药锅、配方、骨粉和世界生成等共同逻辑需要服务端安装同版模组。

配置位置沿用上游：

- `config/bedrockify/bedrockifyClient.json`：客户端功能。
- `config/bedrockify/bedrockifyCommon.json`：共同玩法功能。
- `config/bedrockify/bedrockifyMixins.json`：注入功能开关，修改后重启游戏。
- `config/bedrockify/inventoryUiState.json`：物品栏分类、展开组、搜索词与列表位置。

## 本地构建

需要完整 JDK 17，首次构建需要联网下载 Gradle、Minecraft、Forge 和依赖。

```sh
./gradlew build
./gradlew runClient
./gradlew runServer
```

Windows 使用 `gradlew.bat build`、`gradlew.bat runClient`。

正式游戏应使用 `build/libs/bedrockify-forge-1.9.1-forge-alpha.11+mc1.20.1.jar`。`-dev.jar`、`-sources.jar` 不是安装包。

采用 Architectury Loom 的 Forge 模式，开发时保留 Yarn 名称以减少无关的源码重命名；发布包会重映射到 Forge 的运行时名称。**运行时不需要 Fabric Loader、Fabric API 或 Architectury API。**

## 首轮迁移范围

保留并适配了上游 HUD/坐标与纸娃娃、物品提示、向前搭桥、飞行惯性、聊天与动画、加载画面、炼药锅、配方、骨粉、火焰附加点火、动物进食粒子、枯树与倒木等源码。每项实际验证情况见 `docs/PORTING.md`；源码已适配不代表所有交互都已验证。

首轮已在 Forge 开发环境验证进入世界、B 键配置保存、聊天、骨粉催生甘蔗、药水与染色炼药锅。alpha.2 新验证了非潜行搭桥、创造飞行减速、三种配方模式、中文配置与默认值保存；用户反馈 alpha.2 在纯净测试环境和 158 个模组的环境中均正常，修改后的物品行为能与其他行为模组配合。用户随后反馈 alpha.4 创造栏未检出故障，主流模组兼容正常。这些反馈不包含新加入的生存界面。Forge 覆写的部分 HUD 安全区和经验条样式仍需补齐，完整联机尚未验证。各轮记录见 `docs/ALPHA2.md` 至 `docs/ALPHA6.md`。

## alpha.11：选项背景与搜索栏修正

原版选项菜单及视频、声音、语言、控制、按键、聊天、辅助功能等设置子页面沿用旋转全景，列表背景随开关恢复。创造栏搜索文字移除额外阴影，改在面板和物品绘制后独立绘制，并限制在输入框范围内。源码包名改为 `dev.bedrockify.forge`，保留原 mod ID、资源 ID、配置文件及高级功能键；许可证和来源记录继续保留。

水色仍使用 Java 原版群系水色，并叠加原有环境颜色噪声。投射物只完成资料核对，本轮未修改弓箭、雪球等物理参数：公开的箭实体示例没有完整证明参考版本弓的最终发射速度。详情见 [docs/ALPHA11.md](docs/ALPHA11.md)。

## alpha.10：直接合成与旋转全景

生存背包和工作台进一步收紧边缘并移除“物品栏”标题。配方首次点击选中和填料，再次点击合成一次；Shift 点击最多合成一组成品，材料不足时合成可用数量。世界选择、世界生成和进入世界的加载背景默认使用 Minecraft 1.20.1 原版旋转全景，保持加载框、提示和菜单操作。界面设置中的“菜单全景背景”可关闭该背景，资源包仍可替换全景素材。历次更新简表见 [CHANGELOG.md](CHANGELOG.md)。

## alpha.9 的界面状态记忆与快捷栏修正

- 创造栏各标签、生存背包与工作台分别记忆分类、分组、列表位置和搜索词，重开或重启后恢复。
- Forge 显示页与选中标签分别记忆；原版保存快捷栏及背包特殊页仍沿用原布局。
- 设置中可分别关闭状态记忆与搜索词记忆；状态只保存轻量文本和位置，不缓存整份物品/配方列表。
- 经典 HUD 选中框恢复中性灰白色，保留 alpha.8 的其他修复。详情及验证范围见 `docs/ALPHA9.md`。

## alpha.8 的布局、搜索与 JEI 修正

- 收紧背包及工作台的顶部、右侧和合成区域下方留白，左右面板直接相接；配方列表底框略下移。
- 搜索框点击后获得焦点，支持原生键盘及中文字符事件，搜索与筛选不重复计算材料匹配。
- JEI 的配方快捷区域跟随可见合成箭头，不再覆盖合成输入格；原版界面和其他容器保留各自的点击区域。
- Forge 47.4.0、JEI 15.56.0.205、Curios 5.14.1 环境中完成 319 次回归操作，并检查实际键盘输入、鼠标打开 JEI 和 Curios 扩展背包恢复。

详见 `docs/ALPHA8.md` 及 `docs/qa/survival/results/alpha8-*`。

## alpha.7 的槽位、翻页与外观修正

创造物品列表末尾没有物品的占位槽不再接受悬停、点击或快捷键取物；真实背包、快捷栏、盔甲和副手的空槽仍可正常使用。配方翻页按钮使用清晰的像素箭头，只有一页时也显示深灰色禁用图标，并提供中英文提示。

生存背包的黑色角色区域改为 60 × 80 的窄高比例，盔甲栏紧贴左侧，副手位于角色区域右下。槽位使用单层细边，主面板使用阶梯拐角；创造栏同步采用这套边框。2 × 2 和 3 × 3 合成箭头改为像素图形。外观按参考图的像素结构绘制，并保留生存界面图集的资源包覆盖能力。

说明与本轮验证见 `docs/ALPHA7.md`。

## alpha.6 的显示与图标修正

右侧背包和工作台面板右上角使用独立的配方栏按钮，支持显示/收起，不依赖原版按钮的位置与可见性。只有玩家点击此按钮才保存开闭偏好，其他模组临时关闭原版配方书不会把关闭状态永久保存。复用界面时检查尺寸和布局状态，并在退出经典布局后恢复原版背景尺寸。原版配方书仅在当前屏幕实际使用经典布局时被替换。

创造模式标签去掉物品图标后额外的一层矩形底色，标签本身的边框和选中状态保留。详细说明与验证记录见 `docs/ALPHA6.md`。

## alpha.5 的生存背包与合成

- 新增基岩经典风格的生存背包、2 × 2 合成和工作台 3 × 3 合成页面。原来的盔甲、副手、玩家槽位、合成处理器和网络操作保持原有身份；关闭界面时恢复槽位位置。
- 左侧配方页含建筑、装备、物品、自然分类，支持折叠分组、分页、滚轮、中文/物品 ID/配方 ID 搜索、`#标签` 搜索和仅显示可合成配方。只显示玩家已解锁且适合当前合成网格的原版配方书配方。
- 点击配方填入材料，再从结果槽取出成品；Shift、拖拽和键盘快捷操作沿用 Minecraft 原逻辑。不会替换服务器的配方判定，也不生成材料组合。
- 配方分类缓存随配方或语言更新；材料检查随背包和合成输入更新；分类、搜索和折叠不重复检查材料。每帧最多绘制 48 个配方格。
- JEI 的配方书避让范围同步到新布局；Curios 等自定义背包保留各自界面。附加槽位、非原版屏幕类或窗口不足 470 × 250 个 GUI 单位时使用原界面。
- B 键 → 界面 → 基岩版生存背包与合成，可分别关闭布局或分组，重新打开界面生效。高级兼容开关修改后重启。
- 外观贴图为 `assets/bedrockify/textures/gui/survival.png`，可由资源包覆盖。资源包可替换背景、槽位和按钮外观；移动交互区域、改变分页或暂停菜单布局仍需代码。

验证方法、压力测试观测值及边界见 `docs/ALPHA5.md` 和 `docs/qa/survival`。

## alpha.4 的修正

移除分组加号、减号的黑色底板，改用白色符号及字形描边。经典网格改用独立选物库存，原版共享库存维持 45 格；进入已保存的物品栏前恢复原版布局并释放旧分类引用。保存记录仍使用 Minecraft 原来的读写实现。改动与验证范围见 `docs/ALPHA4.md`；用户后续未检出故障，原先内存耗尽的具体抛出位置未取得堆栈确认。

## alpha.3 的创造物品栏

- 参考基岩版 1.21.9 的经典界面，新增建筑、装备、物品、自然四大分类，以及最大 17 列 × 7 行的大网格；内容仍为 Java 1.20.1 与已安装模组实际提供的物品。
- 同类物品默认折叠。左键点击带 `+` / `−` 的组图标展开或收起，右键取代表物品；右上角 `+` / `−` 可展开或收起当前分类的所有组。搜索结果始终平铺。
- 保留 Forge 原来的上下分类栏、翻页箭头、模组独立分类、背包页和已保存快捷栏。读取 Forge 构建后的物品列表，保留模组追加物品及其 NBT 变体；未定义的模组物品保持平铺。
- 背包页与已保存快捷栏使用原来的专用布局。窗口不足 260 × 230 个 GUI 单位时自动恢复完整 Java 创造栏，以保留所有原版分类与物品。
- B 键 → 界面 → 基岩版创造物品栏，可分别关闭经典布局或折叠分组，重新打开物品栏生效；如与其他创造栏界面模组有冲突，可在高级兼容设置关闭对应注入并重启。

## alpha.2 的设置与配方

- 中文配置、搜索框与高级兼容设置已补齐名称和说明。高级兼容开关保留原来的内部配置键，修改后需重启游戏。
- 前向搭桥辅助默认不要求潜行，仍需站稳、靠近边缘、向下看并将准星指向空处。边缘距离的初始默认与“恢复默认”统一为 0.5 格。
- 创造飞行松键后改为渐进减速。“飞行减速强度”默认 25%，0% 保留原版惯性，100% 为立即停止；关闭自定义减速则使用 Java 原版行为。该设置不改变鞘翅滑翔。
- 鞘翅选项明确为“按跳跃键结束鞘翅滑翔”，默认跳跃键为空格，结束后正常下落。
- 隐藏 Java 版副标题默认开启。未接入功能的 Panorama 设置页已移除。
- 默认采用基岩 1.20.10 后的船、木桶与蛛网规则：船不需要木锹，木桶使用木板，蛛网不能合成线；保留其他基岩染色兼容规则。
- 羊毛与床的覆盖配方现在使用 1.20.1 的实际配方 ID；Java 原版本身已支持它们的跨颜色重染。
- “旧版基岩配方（怀旧）”默认关闭，启用后恢复需要木锹的船、木棍木桶和蛛网合成 9 根线。它依赖“基岩版合成与染色规则”；修改配方后需重新打开世界。

升级时用新 JAR 替换旧 JAR。已有配置会保留用户的选择，不会自动覆盖。若从 alpha.1 升级后仍要求潜行或仍显示 JAVA EDITION，请在 B 键设置中将“仅潜行时辅助放置”关闭、“隐藏 Java 版副标题”开启，或分别点击这两项的恢复默认按钮。

首轮未迁移的配套集成：

- Fabric Indigo 渲染器专用补丁。
- Sodium / Fastload 的 Fabric 兼容补丁。
- AppleSkin 的安全区 HUD 联动。
- 上游内嵌 Panorama Screens 全景背景依赖。
- Fabric 数据生成入口。预生成的配方、战利品表和世界生成 JSON 已保留。

Embeddium / Rubidium 安装时自动停用部分旧光照注入；Oculus 安装时停用上游自定义光照注入。这是保守处理，尚不能视为已验证的整合包兼容性。
