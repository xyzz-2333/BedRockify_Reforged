# BedrockIfy Reforged

本仓库基于BedrockIfy，把部分基岩版特性带到 **Minecraft 1.20.1 Java**。

当前开发版本：**alpha.17**

## 功能一览

**物品栏与合成**

- [x] 生存背包和工作台换成基岩经典双栏布局，保留盔甲、副手、快速移动、拖拽等原版操作。
- [x] 创造栏改为建筑、装备、物品、自然四大分类和大网格，同类物品（木板、楼梯、羊毛、砂岩、农作物等）可折叠。
- [x] 创造目录可在「完整目录 / 双栏 / 仅物品栏」三种视图间切换，双栏时右侧保留玩家背包与 2×2 合成。
- [x] 左侧配方栏按用途分类，可折叠同类配方、翻页，并搜索名称、物品 ID、配方 ID 或 `#标签`；可只看「现在能做的」。
- [x] 点一次配方填入材料，再点一次直接合成；Shift 点击一次做满一整组，材料不够时按现有数量做。
- [x] 重开界面或重启游戏后，会记住分类、折叠、页码、搜索词和创造目录视图；可在设置中关闭。
- [x] 兼容已安装模组的物品、分类和染色/附魔等特殊变体。

**HUD 与界面**

- [x] 坐标、帧率、纸娃娃、区块地图；纸娃娃可设常驻显示、大小、位置和动作停留时长，并显示举盾、游泳、滑翔、爬行、进食、骑乘等动作。
- [x] 血量、饥饿、护甲、氧气、坐骑血量等状态条支持安全区偏移与透明度渐隐。
- [x] 聊天框、加载画面、保存提示改为基岩风格，可调整安全区。
- [x] 手持物品名称与信息提示，含附魔、药水效果和容器内物品。
- [x] 快捷栏半透明、物品格高亮颜色、拖动物品放大、空手摆动速度、进食动画、快捷栏动画。
- [x] 书与笔改为双页编辑，左右页可点击切换，沿用原版文字限制、签名与保存；窗口过小时回退单页。
- [x] 主菜单隐藏 JAVA EDITION 副标题；设置界面中英文完整，可按键 B 或在选项菜单、模组列表打开。

**视觉与氛围**

- [x] 方块表面明暗、太阳眩光、环境颜色噪声、剪毛后保留绵羊颜色。
- [x] 水面与水下颜色按 64 个原版群系套用基岩色，支持资源包改色；未识别的模组群系保留原色。
- [x] 寒冷群系降雪时树叶分八级渐白，雪停后逐步恢复；流畅画质保留原色。
- [x] 第三人称进食动画、手持物品动画与立体钓鱼浮漂。

**世界与玩法**

- [x] 潜行时自动举盾，取消潜行即放下；纸娃娃同步显示举盾动作。
- [x] 基岩式盔甲架：默认带手臂、可手持装备，潜行切换 13 种姿势，支持八方向放置与红石信号控制姿势。
- [x] 炼药锅可盛放染色水和药水，能用水色给皮革装备染色。
- [x] 基岩版合成与染色规则，可切换回旧版基岩配方（船要木锹、木桶用木棍等）。
- [x] 慢速自然回血（默认每 4 秒回半颗心）、攻击无需蓄力、锋利附魔每级多 1.25 点伤害，均可在设置中调整。
- [x] 枯树与倒木会自然生成；骨粉能催生甘蔗、在草地上长出蕨；喂食动物有进食粒子；火焰附加工具可点燃蜡烛和 TNT。
- [x] 前向搭桥（不要求潜行）、创造飞行松键后渐进减速、按跳跃键结束鞘翅滑翔。

**战斗、投射物与装置**

- [x] 基岩式末影珍珠、弓弩箭与投掷三叉戟的速度和重力。
- [x] 穿刺附魔在近战和投掷命中时，按目标是否接触水或雨计算额外伤害。
- [x] 反复点亮下界传送门会生成僵尸猪灵（闪门刷怪），遵守游戏规则与难度；和平难度不生成。
- [x] 三叉戟搅拌机：活塞、活板门或地毯推动无忠诚三叉戟时造成伤害，保留附魔、抢夺与伤害归属。
- [x] 基岩版 82 项成就，分「初入世界」到「技艺精通」七个章节，使用原版进度树与存档。

**教育版内容**

- [x] 118 种元素与未知元素方块。
- [x] 四个化学工作台：元素构造器（调质子、电子、中子造出元素）、化合物创建器（37 种化合物配方，按元素比例匹配）、实验台（反应产出漂白剂、热块、冰弹、超级肥料）、材料分解器（把物品拆成元素）；同一工作台同时只允许一名玩家使用。
- [x] 强化玻璃与玻璃板（无色及 16 色染色，可被信标染色）、水下 TNT（爆炸能穿过水，固体方块照常抵挡）。
- [x] 水下火把与蓝/红/紫/绿彩色火把；漂白剂（把染色羊毛、地毯、床、旗帜洗白）、热块（融化附近冰与雪）、冰弹（把水冻成冰）、超级肥料（作物直接成熟）。
- [x] 装饰用旧切石机、发光黑曜石、下界反应核。
- [x] 衰变药水，含饮用、喷溅、滞留与药水箭四种形式。
**其他**

- [x] 游戏内配置界面、中英文设置说明与新增物品多语言名称。
- [x] 基岩版鼠标手势不作移植，考虑到鼠标手势已经是普遍应用的辅助模组了。

## 安装与配置

1. 安装 Minecraft 1.20.1、Forge 47.4.0 和 [Cloth Config 11.x 的 Forge 版本](https://modrinth.com/mod/cloth-config/version/11.1.136+forge)。
2. 将 `bedrockify-forge-1.9.1-forge-alpha.17+mc1.20.1.jar` 放入 `mods`。
3. 按 **B** 打开配置，也可从 Forge 模组列表或游戏选项进入；快捷键可修改。
界面与视觉效果在客户端生效；配方、教育内容、成就及其他共同玩法需要服务端安装同版模组。

配置沿用 `config/bedrockify/`：

| 文件 | 用途 |
| --- | --- |
| `bedrockifyClient.json` | 客户端功能 |
| `bedrockifyCommon.json` | 共同玩法 |
| `bedrockifyMixins.json` | 高级注入开关，修改后重启 |
| `inventoryUiState.json` | 物品栏分类、分组、搜索与滚动位置 |

## 兼容性与边界

- Embeddium / Rubidium 安装时停用部分旧光照注入；Oculus 安装时停用上游自定义光照注入。
- 与其他背包或创造栏界面冲突时，可在 B → 高级兼容设置关闭对应注入并重启。
- AppleSkin 安全区 HUD 联动尚未迁移；鼠标手势不在本项目移植范围内。
- 未完成的功能和具体校准事项统一记录在 [更新计划](docs/ROADMAP.md)。

## 开发与文档

需要完整 JDK 17；首次构建需联网获取 Gradle、Minecraft、Forge 和依赖。Windows 使用 `gradlew.bat`，其他平台使用 `./gradlew`。

```sh
./gradlew compileJava validateRefmap validateBedrockAdvancements
./gradlew runClient
./gradlew runServer
```

仅准备发布时执行不带测试属性的 `./gradlew clean build`。项目使用 Architectury Loom 的 Forge 模式和 Yarn 开发名称，发布时重映射至 Forge 运行名称。
